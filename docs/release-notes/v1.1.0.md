微信虚拟伴侣首个开源版本：屏幕捕捉 + 键鼠模拟，在本人已登录的 PC 微信里自动收发消息，由 DeepSeek 生成符合人设的回复。

**不注入 DLL、不逆向协议、不读写微信内存**，数据全部留在本机。

### 新增

- 开源仓库结构：`.gitignore`、`.gitattributes`、MIT `LICENSE`、`CONTRIBUTING.md`、GitHub Actions CI
- 配置持久化测试：密钥剔除、原子写入、扩展字段保留
- `assets/README.md`：说明标定截图的隐私风险，截图默认不入库

### 变更

- 控制台保存配置改为写入 `local_config.json`，不再改写 `src/wechat_companion/config.py`
- `config.py` 仅保留可公开的默认值，真实目标微信号、联系人、人设通过本地配置或环境变量提供
- `DEEPSEEK_BASE_URL` 可通过 `local_config.json` 覆盖，便于接入兼容接口
- README 重写：快速开始、配置优先级、架构、测试、打包、隐私与合规

### 修复

- 干净检出（无 `local_config.json`）时测试不再依赖本机私有配置，CI 在 Python 3.9 / 3.12 下通过

### 安全

- 仓库不含真实微信号、聊天截图、DPAPI 密钥、日志与统计数据库

**完整变更见 [CHANGELOG.md](CHANGELOG.md)。**

> 自动化操作微信可能违反微信服务条款并带来账号限制风险，请自行评估、合规使用。
