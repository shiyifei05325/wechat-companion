# v1.2.1 - 微信虚拟伴侣

本次更新包含 1.2.0 的安全加固与能力增强，以及 1.2.1 全量逐字节复查后的缺陷修复。
**不注入 DLL、不逆向协议、不读写微信内存**，数据全部留在本机。

## 1.2.1 修复

- **P1**：修复控制台点击启动即返回 500 的问题（`Popen.wait` 误用不存在的形参，进程此前已实际启动）。
- 环境检测补齐 `pynput`、`winocr`，避免热键与 OCR 兜底在新机器上静默失效。
- 控制台保存配置后的回读校验，对密钥/环境变量覆盖字段跳过等值比对，不再保存成功却误报 500。
- 机器指纹改为 CIM 优先、注册表兜底，解决 Win11 移除 wmic 后指纹降级的问题。
- 区域截屏增加上界钳制，窗口缩放/标定偏差时不再越界抓取。
- 未找到微信窗口时友好退出，不再抛异常。

## 1.2.0 安全加固

- **修复打包态进程爆炸**：打包后环境检测误判内置依赖缺失，反复自我拉起 pip 安装直至内存耗尽。
  打包态彻底禁用 pip/在线安装，启动器拒绝 `-m`/`pip`/`ensurepip` 等危险自调用。
- 新增 Windows 命名 Mutex 单实例保护，整机仅运行一个控制台实例。

## 1.2.0 新增

- **OCR 读消息兜底**：右键复制失败时，用 Windows 内置 OCR（winocr，无 PyTorch）识别气泡文字并清理多余空格。
- **全局热键事件化**：pynput 监听替代轮询，依赖缺失时自动回退。
- **会话历史持久化**：对话历史写入 SQLite，重启后恢复多轮上下文；按“条数 + token 上限”双约束裁剪。
- 接口故障熔断：连续失败 3 次后熔断 30 秒，避免密集重试。
- 区域截屏：空闲轮询只抓消息区，降低 CPU 与内存占用。
- 统计库自动清理 30 天前事件并回收空间；端口占用友好提示。
- 控制台新增「识别与记忆增强」卡片，可可视化配置 OCR 与记忆策略。

## 测试与文档

- 全量用例达到 **79 项**，新增记忆存储、OCR、历史裁剪等专项测试。
- README 目录树、配置表、控制台说明与手工配置示例同步更新。
